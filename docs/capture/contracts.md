# Window content capture interfaces

User request: Drops must read what is ON its anchored window: terminal output, editor code, browser text and images for vision-capable models. Work only on assigned paths. No commits, desktop permission weakening or reading browser profiles/auth/.env files. Test only disposable windows and fixtures. Capture runs on user Send, not in the geometry loop.

## Text helper (scripts/capture_text.py)
Standalone Python, invoked with `/usr/bin/python` (system PyGObject/AT-SPI is available; mise Python lacks gi). One JSON input line = existing context bundle with window {pid,title,class,geometry:{x,y,width,height}}, process cwd. Optional `capture_options` bounds accessibility/terminal, `max_text_chars`, `max_nodes`, `max_depth` and `budget_ms`; each is clamped to a hard limit. Output JSON {"sources":[{"kind":"accessibility"|"tmux","text":"...","scope":"matched-window"|"terminal-scrollback", ...}],"warnings":["..."]}. No screenshots in this helper. Main Rust calls with timeout and clamps all output. Only return text from the matching application AND matching top-level window. Prefer exact window title match; ambiguous or unlocatable windows => report unavailable, never collect other frames. Skip password/protected nodes. Bound nodes/text/time, no clipboard/focus changes or synthetic input. TMUX optional: match client PID ancestry under anchored terminal PID, not arbitrary active pane; capture-pane only after unambiguous matching. Graceful missing GI or AT-SPI. Helper source embedded by Rust via include_str! so no runtime path setup required. Tests under tests/text_capture/ only, fixture fake tree objects plus live disposable GTK text window if feasible. Do not edit Cargo, capture Rust or other tests.

## Capture Rust module (crates/buddy-anchor/src/capture.rs)
Own this file only plus your dedicated tests file crates/buddy-anchor/tests/capture.rs (if needed); parent handles module declaration and Cargo dependencies. Public serde Clone Debug `CaptureConfig` with defaults: enabled:bool=true, accessibility:bool=true, terminal:bool=true, screenshots:bool=true, ocr:bool=true, max_text_chars:usize=24000, max_image_edge:u32=1280, timeout_ms:u64=2500. On-demand full text adds full_text:bool=true, full_max_text_chars:usize=500000, full_max_nodes:usize=50000, full_max_depth:usize=120, full_budget_ms:u64=8000, full_timeout_ms:u64=12000; `pub async fn full_text(context:&Value, config:&CaptureConfig, cancel:CancellationToken) -> anyhow::Result<FullText>` returns the larger accessibility/tmux capture without a screenshot. The daemon caches it per turn and exposes it through the read-only `window_content` tool. Public `pub async fn enrich(context:&mut serde_json::Value, config:&CaptureConfig, vision:bool, cancel:CancellationToken) -> anyhow::Result<()>`. Headless/non-window contexts no capture. Return content in context["content"] = {"status":"captured"|"unavailable"|"disabled","sources":[...],"text":"...", "warnings":[...], "image":{ "mime_type":"image/png", "width":n,"height":n,"data_url":"data:image/png;base64,..."} optional only if vision && screenshots enabled}.
Call text helper with context input and finite timeout; scripts/capture_text.py being implemented in parallel (may appear later). `enabled=false` no commands. Screenshot ONLY anchored visible window rect, reject hidden/offscreen/partially off-monitor/occluded targets rather than silently capturing another window. Use fresh clients/monitors snapshot if necessary; context includes anchor address. grim `-g ... -` stdout with timeout, no disk screenshot/log data. Do NOT focus, raise, inject keys, read clipboard or change desktop config. If screenshot unavailable (Hyprland consent, missing tool, overlap, hidden) add actionable warning, text can still work. Screenshots run locally for OCR even vision=false but image must not appear in context for text-only models. OCR with tesseract stdin stdout only when accessibility/tmux absent or inadequate; no dependencies installed globally. Downscale before sending via image crate to max edge, bound decode/output size and helper stdout, cancel subprocesses kill_on_drop, timeout returns warnings not failed chat. Text sources and capture provenance inspectable. Declare assumed dependencies to parent promptly. Pure image/geometry/vision-gating tests; mock grim/helper command tests possible. Parent handles provider wire: extracts content.image data_url into OpenAI image_url user content and sanitizes metadata JSON, so it is not sent as text/base64.
